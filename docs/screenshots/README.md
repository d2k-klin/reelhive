# `docs/screenshots`

**Overview.** Studio screenshots used by [the studio tour](../studio.md).

| File | Shows |
| --- | --- |
| `new-video.png` | The new-video brief form |
| `customise.png` | Customization controls with the music selector |
| `scene-editor.png` | The intro screen fields above the scene timeline |
| `runs.png` | The Runs screen |
| `finished.png` | A finished production with download buttons |

## Extending

Capture at the studio's default desktop size, save as PNG with a short kebab-case name, and reference it from the doc that explains that screen. Delete a screenshot when no doc uses it.
