## Updating

Retake a screenshot when its screen changes visibly: run `reelhive ui`, use either theme at 1440×1000, and keep the same file name so the guide's links keep working. Keep each PNG under about 200 KB.

Tutorial screenshots use the throwaway fake-agent server (`ui/tests/e2e/serve.py --fake`) and sample content, never user credentials or private run files.
