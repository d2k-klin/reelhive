# Music library

ReelHive never generates music at run time. The `music` agent picks a mood and a tempo, and `audio/music_library.py` chooses the closest track listed in `manifest.json`.

## Rules for adding a track

1. **CC0 only.** No "free for personal use", no attribution licences, no "royalty-free" without a licence text. If in doubt, leave it out.
2. Add an entry to `manifest.json` with `file`, `title`, `mood` (one of `upbeat`, `calm`, `inspiring`, `tech`, `dramatic`), `bpm`, `duration`, `source` (the URL you got it from) and `license` (`CC0-1.0`).
3. MP3, 128-192 kbps, ideally loopable: the mixer loops tracks shorter than the video and fades the last two seconds.
4. Keep the library small (10-15 tracks across the five moods). Repository size matters for a clone-to-install tool.

The test suite checks that every listed file exists and every entry is CC0.
